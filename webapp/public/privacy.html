Politique de Confidentialité

Dernière mise à jour : mai 2025

🇨🇭 Conforme au droit suisse & RGPD

1. Qui sommes-nous ?

OptiTank est une application de comparaison de prix de carburant en Suisse, développée et exploitée par Dany Caetano (ci-après "nous", "notre", "OptiTank"). Contact : pro.caetanodany@gmail.com

2. Données collectées

Nous collectons uniquement les données nécessaires au bon fonctionnement de l'application :

  • Données de compte : adresse email, prénom (saisis lors de l'inscription)
  • Données de véhicule : marque, modèle, année, type de carburant (pour personnaliser les résultats)
  • Données de position : localisation GPS approximative, uniquement si vous l'autorisez, pour trouver les stations proches
  • Données d'utilisation : historique de pleins, stations favorites, alertes de prix — stockés dans votre compte Firebase

Nous ne collectons pas de données de paiement, de données biométriques, ni de contacts.

3. Pourquoi nous utilisons ces données

  • Afficher les prix de carburant les plus proches et les plus avantageux
  • Calculer les économies réalisées sur vos pleins
  • Envoyer des alertes de prix si vous les avez activées
  • Synchroniser vos données entre appareils

4. Partage des données

Vos données personnelles ne sont jamais vendues à des tiers. Elles sont partagées uniquement avec :

  • Firebase (Google LLC) — authentification et stockage sécurisé des données
  • TCS (Touring Club Suisse) — source officielle des prix de carburant, aucune donnée personnelle n'est transmise

5. Conservation des données

Vos données sont conservées tant que votre compte est actif. En cas de suppression de votre compte (disponible dans Profil → Paramètres avancés), toutes vos données sont définitivement effacées dans un délai de 30 jours.

6. Vos droits

Conformément au RGPD et à la LPD suisse, vous disposez des droits suivants :

  • Droit d'accès à vos données
  • Droit de rectification
  • Droit à l'effacement (suppression de compte dans l'app)
  • Droit à la portabilité

Pour exercer ces droits, contactez-nous à : pro.caetanodany@gmail.com

7. Sécurité

Toutes les communications sont chiffrées via HTTPS. L'authentification est gérée par Firebase Authentication (Google), qui applique des standards de sécurité élevés incluant le chiffrement des mots de passe.

8. Modifications

Toute modification importante de cette politique sera notifiée dans l'application. La version en vigueur est toujours accessible à l'adresse optitank.online/privacy.
